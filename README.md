# Toxic Habbo v3 - Busca nativa

Versão nativa Android inspirada na página `/busca` mobile do site Toxic.

Recursos:
- Busca via `https://atoxic.com.br/api.php` como backend.
- Fotos, missões anteriores, visuais anteriores, roupas do visual, status, criação, amigos, quartos, grupos e nomes anteriores.
- Cards em estilo mobile/glassmorphism roxo.
- Heads nos cards de amigos.
- Paginação nativa para Amigos/Removidos e Quartos/Antigos.
- Datas formatadas para America/Sao_Paulo.

Para gerar APK no GitHub: Actions > Build Android APK.
