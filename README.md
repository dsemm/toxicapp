# Toxic Habbo v4 - Busca Mobile Clone

App Android nativo, sem WebView, usando https://atoxic.com.br/api.php como backend.

## Correções desta versão
- Fotos do usuário com detecção recursiva de URL de imagem.
- Visuais comprados pelo endpoint from-figure-string com normalização por slots de figure.
- Botões do avatar com rotação real e botão central de roupa.
- Status online/offline usando os GIFs enviados.
- Nomes anteriores acima das fotos.
- Cards de amigos mais compactos/quadrados, heads maiores e selo NOVO reduzido.
- Datas tratadas em America/Sao_Paulo, evitando 21:00 em data sem horário.
- Loader visual durante a busca.
- Grupos/quartos com texto limitado e placeholders quando imagem não carregar.

## Build pelo GitHub Actions
Envie o conteúdo extraído para o GitHub e execute Actions > Build Android APK.
